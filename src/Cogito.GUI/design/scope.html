How it reconstructs any frame

The Scope never runs the engine — it reloads it. To draw the mind at step T, it seeks the nearest keyframe and replays the delta, exactly like video.

Cheap by construction

A cockpit for a mind can't cost more than the mind. Every surface obeys CPU = cadence × per-pass-work.

O(VISIBLE), NOT O(TAPE)

The spine direct-indexes Tape.Ids[scrollY/rowH ‥ +viewH/rowH] — draws the rows on screen and no others, on a 21k-span tape or a 21M one.

LOD OVER 100K RULES

The grammar spatial-culls to the pan region and clusters to super-nodes at low zoom; detail resolves only where you look.

DOWNSAMPLE TO PIXELS

Curves plot one point per column, not per step. A million-step run draws in a screen-width of samples.

SIGNAL-DRIVEN, IDLE = 0

Redraw only on scrub, input, or a live journal append. A paused Scope on a finished run burns nothing.

Build order

Each phase ships a usable instrument. The substrate exists — this is assembly, not invention.

1SPINE

RunReader + chrome + DYNAMICS

The StateAt(T) keyframe-seek/Δ-replay data layer, the tab + timeline shell, and the curve view — mostly an evolution of today's SparklineSurface. Proves the loop and the scrubber end to end.

2FLAGSHIP

TAPE

The culled span spine — the headline view. Direct-indexed viewport, provenance encoding, the shed lane, click-to-inspect a span's full content + witnesses + vest step.

3TOPOLOGY

GRAMMAR

Icicle first (cheap, legible), then the node-graph + LOD + PPMI overlay, then the MergeEvent construction playback.

4FRONTIER

AGENT + live/playback

The vote-tally dissector — the bottleneck-visualizer that earns its keep the moment we test the sharpness fix. Plus live-tail follow and playback transport.
